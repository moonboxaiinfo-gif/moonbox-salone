# Moonbox Salon — Luxury Salon Atmosphere Upgrade

This landing-only pass preserves the existing Moonbox brand, routes, authentication, CTAs and internal dashboard. It shifts the public page from abstract product motion toward a genuine premium salon atmosphere using an original lifestyle hero film, a cohesive editorial salon photo set, an image lightbox, an editorial gallery, a three-step salon story and a dedicated atmosphere-plus-product showcase. The existing dashboard mockups remain clearly product evidence rather than a substitute for salon photography.

All imagery uses either project-local generated assets or stable managed storage paths. The hero and showcase videos are muted, autoplay-capable, looped, mobile-friendly and poster-backed. Image assets use descriptive alt text, responsive object-cover crops, lazy loading below the fold and reduced-motion-compatible video autoplay behavior. No testimonials were added and no internal SaaS screens were redesigned.

The acceptance goal is a public landing page that feels like a premium international beauty brand while still communicating appointments, customers, staff, sales, inventory, reports, online booking and website-building capabilities.
